# Решения
- Работа ведётся в полученной ветке work. Публикация ветки сохраняет текущую версию Pages.
- Фиксированный сид и четыре ретранслятора по BRIEF_GEN. Проверку целевого i3 отделяем от измерений программного Chromium.
- Все шаблоны имеют четыре совместимых граничных порта. Выбор по весу среди совместимых всегда имеет кандидата, поэтому перебор с возвратом не требуется.
