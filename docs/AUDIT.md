# Аудит исходного прототипа c280954

Vite 7, Three.js r180, ES-модули, одна HTML-страница на русском. npm ci, npm run dev; npm run build собирает статическую dist с относительной базой. Серверная часть отсутствует.

src/city.js строит прямой переулок длиной около 48 м, боковые проёмы, баки, фасады и материалы CanvasTexture. Массивы colliders и ambushes передаются в main.js.
src/main.js управляет камерой, вводом и настройкой чувствительности, трассерами, оружием, дождём и засадой. Столкновения по XZ, глаза на фиксированной высоте. Таймер 35 с, перезарядка сразу целого барабана. Финиш привязан к координате двери.
Существующий цикл, звук, меши и обработчики ввода можно развивать по отдельности. Для генератора нужны общий с ботом запрос высоты пола и сменяемый набор коллайдеров.
