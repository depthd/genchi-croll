# Genchi Croll · Сектор 01 «Переулок»

Сознание просыпается в корпусе андроида. Возьмите револьвер со стола на ходу и доберитесь до ворот башни. У первого тела 75 секунд. Каждая из четырёх зелёных площадок добавляет 30 секунд и становится точкой переноса. Между телами город сохраняется. «Новая кампания» создаёт другой сид.

## Запуск

Требуются Node.js 22.12+ и браузер с WebGL 2.

```sh
npm ci
npm run dev
```

Для статического хостинга выполните `npm run build` и разместите содержимое `dist/` целиком, включая worker в `assets/`. Сборка использует относительные пути. Для просмотра локальной сборки выполните `npm exec -- vite preview`.

## Управление

WASD — движение, Shift — спринт, пробел — прыжок, мышь — обзор, ЛКМ — выстрел, R — дозарядка, Esc — пауза. Стрелки позволяют поворачивать камеру. Стрельба прерывает дозарядку после вставки патрона. Подбор, двери, люки и подъём по стремянке срабатывают на ходу. Оранжевый свет обозначает вход, бирюзовый — смену высоты. Чувствительность и громкость сохраняются в браузере.

## Отладка

| Параметры | Назначение |
|---|---|
| `?seed=740` | Фиксированный город, отдельное сохранение |
| `?seed=740&gen=debug` | Каркас, цветная карта слоёв, портов и ретрансляторов |
| `?seed=740&at=seg12&layer=R` | Старт на выбранном сегменте. Слои G, R, I, U |
| `?relay=2` | Старт на второй площадке |
| `?at=start`, `alley`, `fork`, `upper`, `shortcut`, `block`, `yard` | Именованные точки |
| `?debug=1` | FPS, вызовы отрисовки, треугольники, враги и параметры движения |
| `?seed=740&shot=1` … `6` | Фототочки без HUD |
| `?seed=740&bots=1&god=1&layer=U` | Автопроход по выбранному слою. Ошибки движения выводятся в консоль |
| `?res=240`, `270`, `360` | Внутренняя высота рендера |

`window.GAME` предоставляет положение тела, состояние таймера и оружия, список противников, план города и статистику рендера. Просмотр фототочек и отладочные телепорты изолированы от сохранения кампании.
