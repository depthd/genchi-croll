# Second Body v2

40-секундная проба нового звучания после обратной связи по первой версии. Темп 100 BPM, тональный центр фа-диез, минор. Содержит 16 тактов и хвост эффектов.

- [MP3 для прослушивания](second-body-v2-sketch.mp3).
- [WAV 48 кГц, 24 бит](second-body-v2-sketch.wav).
- [Исходник рендера](render_sketch.py).

В синтезе баса добавлены пилообразные осцилляторы с фильтром и отдельным контролем саба. Ударные пересобраны, партия риффа переписана. Все звуки синтезируются программно.

Формат и уровни проверены технически. Прослушивание внутри текущей модели недоступно. Это набросок для оценки тембров и музыкального направления.

Для повторного рендера понадобятся Python 3, NumPy, SciPy и FFmpeg. Запусти python render_sketch.py. Файлы появятся в папке renders.
