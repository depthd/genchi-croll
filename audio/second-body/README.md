# Second Body

[Новая 40-секундная проба звучания v2](v2/README.md).

Первое инструментальное демо для основного геймплея genchi-croll.

- Продолжительность 2 минуты 20 секунд, 56 тактов.
- Темп 96 BPM, размер 4/4.
- Тональный центр ре, минор.
- Басовый синтезатор, электронные ударные, металлическая перкуссия, синтезаторный мотив и атмосферные слои.

## Файлы

- [MP3 для прослушивания](second-body-preview.mp3).
- [WAV с бесшовным повтором](second-body-gameplay-loop.wav), стерео, 48 кГц, 24 бит.
- [Архив пяти отдельных дорожек](second-body-stems.zip), стерео FLAC, 48 кГц, 16 бит.
- [Исходник синтеза и аранжировки](render_second_body.py).

Открой нужный файл и нажми **Download raw file**, чтобы скачать его.

WAV содержит ровно 6 720 000 кадров. Для непрерывного повтора зацикли весь файл. Отдельные дорожки начинаются в одной точке, имеют одинаковую продолжительность и вместе воспроизводят мастер с погрешностью квантования 16 бит.

## Происхождение звука

Композиция, партии и тембры созданы программно для этого демо. Все звуки инструментов синтезируются в исходнике. The Rebel Path использован как ориентир по энергии и звучанию. Загруженный референс не читается исходником рендера.

## Повторный рендер

Понадобятся Python 3, NumPy, SciPy и FFmpeg с кодировщиками libmp3lame и FLAC.

```sh
python -m pip install numpy scipy
python render_second_body.py
```

Результат появится в папке renders рядом с исходником.

## Проверка

Формат, отсутствие клиппинга, громкость и непрерывность стыка проверены технически. Измеренная интегральная громкость около −15,3 LUFS, истинный пик около −1 dBTP. Прослушивание автором генерации осталось недоступно из-за ограничений аудиовхода модели. Оценка звучания и баланс с игровыми эффектами требуют прослушивания.
